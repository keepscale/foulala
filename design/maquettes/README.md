# Maquettes

Sources du canevas de design « Foulala · maquettes » (claude.ai, privé).

Ces fichiers `.dc.html` sont au format du canevas : ils ne s'ouvrent pas tels quels dans un navigateur (il leur manque le `support.js` de l'éditeur). Ils servent de référence pour l'implémentation : structure des écrans, textes, couleurs, tailles.

| Fichier | Écran |
|---|---|
| `Logo.dc.html` | Logo, icônes, bouton « J'y suis ! », badge « J'y étais » |
| `Main.dc.html` | Liste des manifs par ville, filtres par cause |
| `Detail.dc.html` | Détail d'une manif, thème par cause (Climat, Fiertés, Paix) |
| `Presence.dc.html` | Après « J'y suis ! » : envoyé, en attente de réseau, hors zone |
| `Compteur.dc.html` | Compteur en direct, arrivées, densité par tronçon |
| `Detail-Fiertes.dc.html`, `Detail-Paix.dc.html` | Le détail dans d'autres thèmes |
| `Themes.dc.html` | Palette des six causes |
| `Organiser.dc.html` | Création d'une manif côté organisateur (web) |
| `canvas.json` | Disposition des planches |

Les données affichées (manifs, chiffres, collectifs) sont fictives.
